# 糯叽机 ⇄ Float 备份转换器 V6

纯浏览器、本地运行的双向备份转换工具。文件不会上传服务器。

## 支持方向

- 糯叽机 `.gz` → Float `.zip`
- Float `.zip` → 糯叽机 `.gz`

## 转换范围

- 用户资料和头像、角色卡和头像、角色私聊
- 世界书、朋友圈
- 糯叽机 → Float 时可将糯叽机论坛导入 Float 小红书
- API 预设仅转换：API 地址、Key、模型名称、接口类型、流式输出、温度
- 剧情可选择仅剧情 App、仅线下消息或两者都导入

Float 反向转换时，不同角色完全独立。同一角色同时导入两类数据时，会在糯叽机剧情聊天中建立“剧情”和“线下”两个分页；多个剧情会话保留为独立分页，不会与线下消息混合。

Float → 糯叽机不转换角色记忆、Float 小红书/论坛和群聊。由于糯叽机是非开源项目，角色记忆表结构无法可靠确认，建议根据原聊天内容手动总结。导入后请检查角色卡性别；若角色列表暂时没有显示消息，请进入通讯录点击对应好友查看。

V5 按糯叽机真实备份结构修正了 Float 媒体头像、世界书、私聊会话关联、剧情数字分页和朋友圈字段。世界书使用安全字段转换，不再直接复制 Float 对象。

## 大文件模式

文件达到 100MB 时页面会自动显示清理建议，转换器只匹配核心模块。建议先在原应用清理音频、壁纸、贴纸、图片/地图缓存、小说和不用的应用数据。浏览器仍需解压糯叽机的单体 GZIP，因此超大备份若内存不足，建议先清理后重新导出。

不会导入多人场景、家园、情侣空间、异世界、自定义游戏、Minimax、图片/语音 API，以及 Float 专属工具、主题、桌面和缓存。

## GitHub Pages

仓库根目录为已构建静态文件时，在 `Settings → Pages` 选择 `Deploy from a branch`、`main`、`/(root)`。无需服务器或云函数。

首次请在空白测试环境导入并核对角色、头像、消息、剧情分页和 API 配置，再用于正式数据。
