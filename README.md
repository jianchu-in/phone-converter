# AI 手机备份转换器

把“网站一”的 `.gz` 用户备份转换为 `ai-virtual-phone` 可导入的原生 ZIP 备份。全部数据只在浏览器本地处理。

## 当前转换范围

- 用户身份、角色卡、私聊、基础群聊和消息
- 单一主 API 预设：地址、Key、模型、接口类型；原温度和流式设置保存在迁移元数据中
- 世界一论坛帖子转为网站二小红书笔记（正文最多 3000 字符）
- 剧情聊天可选择：剧情 App、角色线下消息、两处同时导入
- 自动清理常见状态栏、思考标签、控制标签
- 长期记忆和核心事实

不会导入多人场景、家园、情侣空间、异世界、自定义游戏、Minimax、图片/语音 API。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## GitHub Pages 部署

1. 新建 GitHub 仓库，把本目录全部文件上传到仓库根目录。
2. 在仓库 `Settings → Pages → Build and deployment` 中选择 `GitHub Actions`。
3. 推送到 `main` 分支，工作流会自动构建并发布。
4. 链接通常为 `https://用户名.github.io/仓库名/`。

## 安全

转换器没有后端、上传接口、统计脚本或远程存储。若选择“完整迁移”，输出 ZIP 会包含原 API Key，请妥善保管。

## 使用建议

首次请在网站二的空白测试环境导入。验证角色、会话、消息、剧情和 API 配置无误后，再用于正式环境。
