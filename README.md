# 手机备份 → Float 转换器 V7

纯浏览器离线备份转换器。备份只在当前浏览器中读取和生成，不会上传到服务器。

## 支持方向

- 糯叽机 `.gz` → Float `.zip`
- ePhone Legacy `.json` → Float `.zip`
- 兔K机 / 330 等与 ePhone 使用相同 Legacy 数据表的互通备份 → Float `.zip`
- Float `.zip` → 糯叽机 `.gz`

## ePhone / 兔K机 / 330 → Float

转换器会同时识别两种常见结构：数据表直接放在 JSON 顶层，或放在 `data` 对象中。缺少某个可选数据表时会跳过该模块，不会让整次转换失败。

当前转换：

- 角色卡、角色头像和人设
- 独立 NPC 与群成员角色卡
- 私聊、基础群聊及聊天消息
- 群聊成员和消息发言人关联
- 世界书及条目
- 用户昵称、头像和用户人设
- 空间动态 → Float 朋友圈
- 空间评论 → Float 朋友圈评论
- API 地址、Key 和采样参数
- 角色与世界书、用户身份和默认 API 的基础绑定

ePhone 的剧情、线下、旁白等消息本来保存在聊天历史中，因此会保留在原私聊或群聊，不重复创建 Float 剧情页。

不转换：贴纸库、角色长期记忆、通话记录、外观、钱包、阅读、游戏、音乐及缓存数据。ePhone Legacy 备份没有模型名时，导入 Float 后需要手动选择模型。

## 糯叽机 → Float

- 用户资料与头像
- 角色卡与头像
- 私聊与基础群聊
- 世界书
- 朋友圈
- 论坛 → Float 小红书（可选）
- 剧情 App 与线下记录（可选）
- 角色记忆
- API 预设

## Float → 糯叽机

因糯叽机不是开源项目，目前仅转换已经用真实备份验证的角色核心数据。Float 群聊、角色记忆和小红书/论坛不会反向转换。导入后请检查角色性别；若列表没有显示消息，可从通讯录点击好友进入聊天。

## 部署

仓库根目录保留以下 5 个文件：

- `index.html`
- `main.js`
- `style.css`
- `worker.js`
- `README.md`

GitHub Pages 选择 `main` 分支和 `/(root)`。部署更新后建议强制刷新页面。

## 大文件说明

ePhone Legacy JSON 可能把贴纸和媒体直接写入一个巨大文件。转换器不会把无关大区写入 Float，但浏览器仍需先解析原始 JSON。超过 100MB 建议使用电脑 Chrome 或 Edge；手机浏览器可能因内存上限直接关闭后台线程。
